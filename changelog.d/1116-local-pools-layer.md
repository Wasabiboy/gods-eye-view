- A new **Pool Spy** data layer (`local-pools`) ships bundled backyard
  pool detections for Mairangi Bay, Auckland, alongside the existing Datacenters
  and Dams infrastructure layers. It reads the same local GeoJSON Lines format,
  registers in the Infrastructure panel group and the voice layer manifest, and
  carries a layer-state token so its on/off state serializes into share links.
  Detection cards show the detector confidence and the NZ parcel the pool falls
  within. These are candidate detections from aerial imagery, not verified
  pools; the bundled file documents its provenance and accuracy caveat.
- The voice layer manifest gained the same layer, so "pools" or "swimming
  pools" turns it on by voice. The Realtime prompt stayed inside its size
  budget by dropping wordings that repeated a policy already stated elsewhere
  (the camera-claim restatement, the hedge example, the verbatim-count hedge
  list, the world-or-news aside); every policy is unchanged.
